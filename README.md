# Instalacje fotowoltaiczne w Zabrzu

Mobilna mapa Leaflet prezentująca lokalizacje planowanych instalacji PV, ich moc i numery działek.

## Funkcje

- 10 punktów inwestycji (11 planowanych instalacji),
- mapa ulic OpenStreetMap i ortofotomapa GUGiK,
- identyfikacja oraz podświetlenie działki po kliknięciu mapy przez ULDK,
- geolokalizacja użytkownika i wyznaczanie trasy,
- układ dopasowany do telefonu.

Wersja działająca: https://instalacje-pv-zabrze.ofek485388.chatgpt.site

## Uruchomienie

Wymagany jest Node.js 22.13 lub nowszy.

```bash
npm install
npm run dev
```
